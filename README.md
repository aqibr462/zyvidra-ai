# Zyvidra AI Video Studio

A responsive front-end prototype for a manual AI video request studio. Visitors can choose Veo 3 or Omni Flash, describe a video, select aspect ratio and preferred duration (5, 8, 10, or 15 seconds), select visual style and audio preference, and optionally attach a reference image.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — responsive visual design
- `script.js` — front-end form interactions and local demo request export

## Important limitations
This is a static prototype. Form submissions are processed only in the visitor's browser and are not sent to the site owner. Reference images are not uploaded to a server. Real customer orders require a secure backend, database, admin notifications, private file storage, and delivery workflow. Model availability, duration, and audio depend on the actual tools and subscription access used for manual production.

## GitHub Pages
Keep all four files at the repository root and configure GitHub Pages to deploy from the `main` branch and `/(root)` folder.
